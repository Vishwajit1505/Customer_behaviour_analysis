This project demonstrates an end-to-end Data Analytics workflow, covering data collection, cleaning, exploration, database analysis, visualization, and reporting. ## How to Run

### Python Analysis

1. Clone the repository.
2. Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open Jupyter Notebook.
4. Run the notebooks in sequence:

   * Data Loading
   * EDA
   * Data Cleaning

### SQL Analysis

1. Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
2. Execute the provided SQL scripts.
3. Review query outputs and insights.

### Power BI Dashboard

1. Open the `.pbix` file in Power BI Desktop.
2. Refresh data connections if required.
3. Explore dashboard visuals and KPIs.
